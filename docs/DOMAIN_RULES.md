# DOMAIN_RULES.md — القواعد القانونية والحسابية

> هذه الوثيقة **مرجع إلزامي**. أي تعديل يمسّ الأرقام أو النصوص القانونية يتطلّب مراجعة بشرية صريحة.
> كل بند مذكور هنا تحقّقنا منه في الكود. البنود المحتاجة لمراجعة قانونية/بشرية مُعلَّمة بوسم **[مراجعة بشرية]**.

---

## 1) مكافأة نهاية الخدمة — `calculateEOS()`

### 1.1 الاستناد والأجر
- `salary = numVal('eos-salary')` — الأجر الشهري الشامل (يُقصد به الأجر الأخير).
- `leaveBasis` (`eos-leave-basis`) يحدّد أساس بدل الإجازة.
- `basicField = $('eos-basic').value.trim()` هو **الأجر الأساسي فقط** عند اختيار أساس "الأساسي".

### 1.2 المدد
```
totalYears = years + months/12 + days/365
```
حيث `years` (0..50) و`months` (0..11) و`days` (0..30) مقصوصة بـ`clamp`.

### 1.3 حساب المكافأة (وفق Code) **[مراجعة بشرية للتحقق القانوني]**
- **المادة 84** — نظام "المكافأة نصف أجر عن أول 5 سنوات ثم أجر كامل":
  - إذا `totalYears ≤ 5`: `first5 = totalYears × (salary / 2)`، `after5 = 0`.
  - إذا `totalYears > 5`: `first5 = 5 × (salary / 2)`، `after5 = (totalYears − 5) × salary`.
  - `full = first5 + after5`.
- **المادة 85** — نسب الاستقالة (`reason === 'resignation'`)؛ الكود يقارن بـ`totalYears < 2` ثم `<= 5` ثم `< 10`:
  | المدة | النسبة | الوسم |
  |---|---|---|
  | أقل من سنتين | 0 | `rUnder2` |
  | من سنتين إلى **5 سنوات ضمناً** | 1/3 | `rThird` |
  | **أكثر من** 5 سنوات إلى أقل من 10 | 2/3 | `rTwoThirds` |
  | 10 سنوات فأكثر | 1 | `rFull10` |
  > الخمس سنوات **بالضبط** ⇒ الثلث (1/3) لا الثلثان، لأن النصّ «لا تزيد على خمس سنوات». مُثبَّت بفحوص حدّية في `tests/smoke_test.py`.
- **المادة 80** — إنهاء بسبب مادة 80: النسبة **0** (`rNone`).
- **المادة 87** — مُنفَّذة كخيارات مستقلّة في `eos-reason`: `force` (ترك العمل لقوة قاهرة خارجة عن إرادة العامل)، `marriage` (العاملة: خلال 6 أشهر من عقد الزواج)، `childbirth` (العاملة: خلال 3 أشهر من الوضع) — وكلّها بالنسبة **1** (`rFull`).
- **الحالات الأخرى** (`expiry`, `termination`, `art81`, وأي قيمة غير معروفة) — النسبة الافتراضية **1** (`rFull`). **[مراجعة بشرية]** استحقاق المادة 81 للحقوق كاملة محلّ تدقيق.

```
netGratuity = full × ratio
```

### 1.4 بدل الإجازة غير المستهلكة
```
if (salary <= 0)                 ⇒ '—' + رسالة eosSalaryRequired (لا حساب)
leaveWage = salary
if (leaveBasis === 'basic'):
    basicField === ''            ⇒ eosBasicRequired  (لا رقم)
    numVal('eos-basic') > salary ⇒ eosBasicTooHigh   (لا رقم)
    otherwise                    ⇒ leaveWage = numVal('eos-basic')
leavePay = (leaveWage / 30) × leaveDays
total    = netGratuity + leavePay
```
- الحقل `#eos-basic` يظهر فقط عند اختيار أساس الإجازة "الأساسي" (`eos-basic-group.hidden`).
- **لا يُخمَّن الأساس إطلاقاً:** افتراض `75%` السابق أُلغي. الأساس الفارغ يطلب الراتب الأساسي الفعلي، والأساس الأكبر من آخر أجر يُنبّه لمراجعة القيم — وكلاهما عبر `showToast` والوسمين `eosBasicRequired`/`eosBasicTooHigh`.
- يُضاف بدل الإجازة دائماً بعد حساب المكافأة — حتى مع المادة 80 (نسبة المكافأة 0) — لأن الكود لا يربطه بنسبة المكافأة.

## 2) التأمينات الاجتماعية (GOSI) — `CONFIG` و`gosiScheme()`

### 2.1 الثوابت
```
GOSI_CAP = 45000            // سقف الوعاء التأميني الشهري
DBR      = 1 / 3            // حدّ نسبة الاستقطاع المتاحة (قاعدة تمويلية، ليست نصّاً)
RATES_UPDATED = '2026-07'
GOSI = {
  expat:   { emp: 0,      er: 0.02    },
  legacy:  { emp: 0.0975, er: 0.1175  },
  new2026: { emp: 0.1075, er: 0.1275  }  // نسبة ثابتة وقت التسجيل فقط، والفعلي يُحسب بـgosiScheme
}
```

### 2.2 النظام الجديد — `gosiScheme(cat, d = new Date())`
للفئة `new2026` فقط:
```
steps   = min(4, max(0, year − 2025 + (month ≥ 6 ? 1 : 0)))
annuity = 0.09 + 0.005 × steps          // 9% تبدأ، +0.5% كل يوليو حتى 11% في 2028
emp     = annuity + 0.0075              // + 0.75% ساند (حصة الموظف)
er      = annuity + 0.0075 + 0.02       // + 2% أخطار مهنية (حصة صاحب العمل)
```
أي: الفئة `new2026` = **أول تسجيل** لمشترك جديد (لا اشتراكات سابقة)، والنسبة ترتفع تدريجياً كل يوليو. **[مراجعة بشرية]** صياغة "النظام الجديد" ونسب ساند/الأخطار المهنية.

### 2.3 الوعاء التأميني
- الفئة `expat` (وافد): `emp = 0` و`er = 2%` فقط (الأخطار المهنية).
- `insurable = min(basic + housing, GOSI_CAP)`.
- **الحدّ الأدنى للأجر الخاضع غير مُطبَّق** (تذكير: يوجد حدّ أدنى نظامي) — **[مراجعة بشرية]**.

## 3) الراتب والاستقطاع — `calculateSalary()`

```
housing    = isEmpty(sal-housing) ? basic × 0.25 : max(0, housingRaw)
gross      = basic + housing + transport
insurable  = min(basic + housing, GOSI_CAP)
gosiEmp    = insurable × scheme.emp
gosiEr     = insurable × scheme.er
net        = gross − gosiEmp
maxDeduct  = net × DBR            // 1/3
avail      = max(0, maxDeduct − obligations)
disposable = max(0, net − obligations)
```
- السكن الفارغ ⇒ `25%` من الأساسي. **[مراجعة بشرية]** النسبة العرفية 25% وليست نصّاً.
- `sal-cap-warn` يظهر عند تجاوز `basic + housing` سقف `GOSI_CAP`.
- **[مراجعة بشرية]** حساب حدّ الاستقطاع على **الصافي** مقابل **الإجمالي** (ممارسة SAMA) قابل للجدل؛ الكود الحالي يستخدم الصافي.

## 4) نظام الفئات والوسوم
- `sal-category`: `expat` / `legacy` / `new2026`.
- `eos-reason`: `expiry` · `termination` · `resignation` · `force` · `marriage` · `childbirth` · `art81` · `art80`. النسبة **0** لـ`art80`، ونسب المادة 85 لـ`resignation`، والنسبة **1** لبقية القيم (بما فيها غير المعروفة).
- وسوم النسب: `rFull`، `rNone`، `rUnder2`، `rThird`، `rTwoThirds`، `rFull10`.

## 5) الخطابات — `generateLetter()`
- 6 أنواع عبر `let-type`: استقالة/طلب زيادة/إجازة/عدم تجديد/شهادة راتب/طلب إداري.
- اللغة عبر `let-doc-lang`.
- التاريخ المطبوع يأخذ `let-date`، وإن غاب يُولّد `localDateStr(new Date())` بصيغة **ISO** (`YYYY-MM-DD`). هذه **صيغة تقنية غير عربية** — **[مراجعة بشرية]** أفضليتها مقابل صيغة عربية مهيّأة عبر `Intl.DateTimeFormat` (Backlog).
- في المستند العربي يُضاف التاريخ الهجري عبر `hijriToday()` (`ar-SA-u-ca-islamic-umalqura`).

## 6) القيود الملزمة (ممنوع التغيير بلا موافقة) **[مراجعة بشرية = الموافقة]**

### 6.1 الهوية البصرية
- `--primary: #0a6847`، `--primary-dark: #075135`، `--primary-light: #12966a`، `--accent: #b45309`.
- مجموعة `--paper-*` تبقى بيضاء في الوضعين — ورقة السيرة الرسمية لا تتلوّن ليلياً.
- `--cv-frame-*` خاصة بالإطار/الظل فقط.

### 6.2 الأسلوب الممنوع (مرفوض بموافقة سابقة)
- قواعد عامة `header { }` / `footer { }` — استخدم `body > header` / `body > footer`.
- تحويل رأس السيرة إلى `<div>` مع ألوان `!important` حرفية.
- `minmax(Npx, …)` في شبكة السيرة — استخدم `minmax(0, …)`.

### 6.3 الإعلانات والتحقق
- سكربت Adsterra **Social Bar** وسكربت **Native Banner** لا يُحذفان ولا يُكرّران.
- أرقام الناشرين وأكواد التحقق بالاسم فقط، لا تُنسخ في أي وثيقة أو ملف.

### 6.4 نصوص لا تُغيَّر
- `shareNote` (ملاحظة الخصوصية داخل شريط المشاركة).
- نصّ إخلاء المسؤولية (§الإخلاء في التذييل).
- أي وصف قانوني/إرشادي ظاهر للمستخدم.

## 7) قائمة المراجعة البشرية (مجمّعة)
1. دقة ترقيم المواد (80/84/85/87) ومحتواها مقابل نظام العمل السعودي.
2. الحدّ الأدنى للأجر الخاضع للتأمينات (تطبيقه من عدمه).
3. حساب حدّ الاستقطاع على الصافي مقابل الإجمالي.
4. دقة صياغة "النظام الجديد" ونسب ساند والأخطار المهنية.
5. صياغة نصّ الخصوصية/الإخلاء والادعاءات (مثل "جميع البيانات تُعالج داخل المتصفح").
6. نسبة السكن 25% كافتراض في أداة الراتب (افتراض الأساس 75% في EOS أُلغي — راجع §1.4).

> لا تُزوّر أرقاماً ولا نصوصاً. أي رقم مخالف لمراجعة بشرية يُسجَّل ولا يُعدَّل تلقائياً.
