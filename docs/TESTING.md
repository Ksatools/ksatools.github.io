## 2) كيف تشغّل

```powershell
# من جذر المشروع
python tests/smoke_test.py

# لاعتبار بنود BACKLOG غير المنفّذة فشلاً أيضاً (صارم)
python tests/smoke_test.py --strict

# لرؤية المتصفّح
python tests/smoke_test.py --headful

# خط أنابيب التسويق: اختبارات ذاتية (بلا شبكة)
python auto_marketing.py --selftest
python auto_marketing.py --dry-run
python auto_marketing.py --verify
# وضع auto الكامل يتطلّب GEMINI_API_KEY (أو مفتاح وهمي في dry-run)
```

**ملاحظة ترميز (Windows):** بعض الفحوص تطبع رمز `→`؛ على طرفية بترميز غير UTF-8 يفشل `print` بـ`UnicodeEncodeError` فيبدو الفحص فاشلاً بلا سبب (تحقّق: بلا UTF-8 ظهر `PASS=20 FAIL=1` ثم توقّف الاختبار، ومع UTF-8 ظهر `PASS=58 FAIL=0 FAIL(known)=13`). شغّلها بـ`$env:PYTHONIOENCODING="utf-8"` أو أعد توجيه المخرجات إلى ملف.

مخرجات كل حالة:
- `PASS` — السلوك مطابق.
- `FAIL` — انكسار حقيقي ⇒ قيمة خروج غير صفرية.
- `FAIL (known)` مع رقم بند — انكسار **متوقّع** يخصّ بنداً في `docs/BACKLOG.md` لم يُنفَّذ بعد. لا يؤثّر على قيمة الخروج افتراضياً، ويؤثّر مع `--strict`.

**سياسة الشبكة:** الاختبار يحجب كل الطلبات غير `file://` داخل المتصفّح، فلا تصل أي بيانات لأي جهة. (لذلك لا تُحمَّل سكربتات Adsterra أثناء الاختبار، وهذا متوقّع — انظر §5.)
**لا يُعدِّل الاختبار أي ملف، ولا يكتب أي بيانات.**

## 3) ما يغطّيه الاختبار

**فحوص ثابتة (بلا متصفّح):** وجود الملف وحجمه، عدم وجود BOM، الانتهاء بـ`</html>`، وجود `gosiScheme` و`store.set`، وجود سكربتَي Adsterra **مرّة واحدة لكل منهما**، خلّوه من آثار الاختبار، صيغة LF فقط، وصحّة صياغة الجافاسكربت (`node --check`).

**فحوص المتصفّح:**
- عدم وجود معرّفات HTML مكرّرة.
- حساب مكافأة نهاية الخدمة (الحالة الافتراضية + بدل الإجازة على الأساسي + الأساس الفارغ).
- تأمينات GOSI للفئات الثلاث (جديد/قديم/وافد).
- مشاركة كشف نهاية الخدمة والاستعادة من الرابط.
- مستند السيرة: أن الترويسة المولَّدة `<header>` بلا خلفية/ظل، والورقة بيضاء.
- فحص \"المقاييس\" في السيرة (أربع حالات).
- **خصوصية مشاركة السيرة:** `#cv-share` بعد تعبئة مثال — لا تسريب اسم/جوال/بريد، تعرض درجة ATS فقط.
- **قسم الأدلة (`section#guides`):** موجود، رسالة خطأ واضحة عند `file://`، لا روابط غير موثوقة، لا أخطاء كونسول.
- التبويبات: النقر + الـhash + `Home`/`End` + أسهم RTL.
- إتاحة/سيو معلّق (نصّ `aria-label`، `meta keywords`، `theme-color`، `data-i18n-html`، حاويات الإعلان الفارغة).
- قبول الأرقام الهندية.
- وجود مفتاح الحفظ المحلي، وخلوّ الكونسول من أخطاء الجافاسكربت.

| `503` مستمرّ | **4 محاولات** ثم فشل واضح «استُنفدت المحاولات» |
| `401` / `403` / `404` (نموذج غير متاح) | محاولة واحدة بلا أي انتظار، وتصنيف واضح (مصادقة/صلاحية/نموذج) |
| `429` حصة يومية/فوترة | محاولة واحدة بلا انتظار (تكرار الطلب بلا فائدة) |
| فشل Groq | لا طلب لأي مضيف آخر (لا `googleapis`) ⇒ لا انتقال تلقائي |
| فشل في وضع `auto` | `rc=2`، بلا نشر وبلا مسودات وبلا تغيير في `articles.json`/`sitemap.xml` |
| غياب المفتاح + `--dry-run` | `rc=0` بلا كتابة (لا ينكسر CI/الاختبار الذاتي) |

**تحقّق إضافي للنقل الحقيقي (خارج المستودع، غير مُودَع):** سكربت محلي شغّل خادم HTTP على `127.0.0.1` (بلا Groq وبلا Gemini وبلا أي شبكة خارجية) واستدعى `groq_generate_json` و`run_once` عبر `urllib` الفعلي — 12/12 PASS: ظرف `chat.completions` صالح يُحلَّل، المضيف/المسار `…/openai/v1/chat/completions`، ترويسة `Authorization: Bearer …`، جسم يحمل `response_format={"type":"json_object"}` و`messages`، `429` حقيقي يُعاد ويُقرأ `Retry-After` من الترويسة فعلاً، `429` حصة يومية لا يُعاد، و`401` حقيقي في وضع `auto` ⇒ `rc=2` بلا نشر وبلا مسودات وبلا ظهور للمفتاح في السجل. هذا يثبت مسار النقل والشكل فقط — **ولا يُعدّ اختباراً لمزوّد Groq نفسه**. (رُصد في هذه الجولة أن `backoff_delay` يطبّق `max(التراجع التصاعدي, Retry-After)`، أي أن `Retry-After` قيمة دنيا لا عليا: `Retry-After: 1` ⇒ انتظار `2s`.)

#### 5.1) اختيار الموضوعات مع فقدان الحالة أو تلفها (القسم 12 في `--selftest`)

**المرجع الدائم لمنع التكرار هو `articles.json`، لا `marketing_state.json`.** الأخير يُخزَّن في Actions عبر Cache غير دائم (إخلاء/حذف/فشل تنزيل)، فإن فُقد فالاختيار يبقى صحيحاً.

الفحوص المضافة:
- `existing_published_pairs`: يقرأ المنشور فقط (`status == "published"`) ويتجاهل المسودات والمدخلات غير الصالحة.
- `pick_topic` لا يعيد موضوعاً اكتملت نسختاه (ar+en) في السجل المنشور، ويختار **الموضوع التالي غير المنشور**.
- موضوع نُشرت نسخته الواحدة لا يُعدّ مكتملاً (يبقى قابلاً للاختيار لإكمال اللغة الأخرى).
- **فقدان الحالة تماماً** لا يكرّر موضوعاً مكتملاً في السجل.
- حالة تالفة (بلا `topics`) لا تُسقط الاختيار.
- حدّ المحاولات يُحترم مع **الإبقاء على `attempts` محفوظاً**.
- `reconcile_state_with_records` يُعلّم النسخ المنشورة `published` ويُبقي `attempts` وحالة اللغة الأخرى (`error`/`rejected`/`draft_unverified`) بلا مسح.

#### 5.2) وضعا `draft` و`auto` (تحقّق سلوكي محلي، بلا شبكة ولا API)

| الحالة | المتوقّع والمتحقّق |
|---|---|
| `draft` | مسودتان في `drafts/`، لا صفحات في `articles/`، `articles.json` و`sitemap.xml` بلا تغيير، الحالة `draft` لا `published` |
| `draft` بنسخة صالحة واحدة | تُكتب مسودة واحدة، والثانية `error`، ولا نشر |
| `auto` ناجح | صفحتان + سجلان منشوران + تحديث الـ`sitemap`، وأكواد الإعلان المعتمدة مرّة واحدة |
| `auto` إعادة تشغيل الموضوع نفسه | لا توليد ولا نشر مكرّر (النسختان مُعلَّمتان منشورتين في السجل) |
| `auto` فشل فحص الصفحة **قبل** النشر | rc=0، لا صفحات يتيمة، ولا تغيير في `articles.json`/`sitemap.xml`، والموضوع **لا يُعلَّم منشوراً** (يبقى قابلاً لإعادة المحاولة) |
| فقدان/تلف/نوع خاطئ لملف الحالة | لا انهيار، ويُختار موضوع غير منشور، والسجل بلا أي زوج (موضوع، لغة) مكرّر |

**تحقّق إضافي مؤقّت (خارج المستودع، غير مُودَع):** أدوات محلية شُغّلت مرّة واحدة ثم حُذفت — `verify_topic_and_modes.py` (27/27)، `check_workflows.py` (30/30 فحوص ساكنة على YAML)، وتنفيذ خطوات `ai_marketing.yml` **منقولة حرفياً** (18/18: خطوة `mode` ترفض قيمة غير مدعومة قبل `GITHUB_OUTPUT`، و`topic` يُمرَّر وسيطاً مقتبساً واحداً، وخطوة `Commit وPush` في مستودع اختباري لا تدفع `marketing_state.json` ولا `latest_social_post.txt` ولا تُنشئ commit فارغاً).

#### 5.3) سياسة إعادة المحاولة ومنع النشر عند الفشل (القسم 13 في `--selftest` — استجابات وهمية بلا شبكة وبلا انتظار حقيقي)

| الحالة | المتحقّق |
|---|---|
| `503` مؤقّت ثم نجاح | نجاح بعد **محاولتين** فقط، مع انتظار تصاعدي واحد |
| `503` متكرّر | **4 محاولات** كحدّ أقصى (`GEMINI_MAX_TRIES`) مع 3 انتظارات `2/4/8s`، ثم `[FAIL]` «استُنفدت المحاولات» |
| خطأ غير مؤقّت (`400` مفتاح غير صالح) | محاولة واحدة، بلا أي انتظار، ووسم «غير قابل لإعادة المحاولة» |
| فشل النسختين | `rc = EXIT_GENERATION_FAILED (2)`، لا صفحات ولا مسودات ولا تعديل على `articles.json`/`sitemap.xml`، و`attempts = 1` فقط |
| نسخة واحدة صالحة في `auto` | `rc=0` + مسودة واحدة فقط + لا نشر ولا سجل مقال |
| غياب مفتاح المزوّد المحدَّد (`GROQ_API_KEY` أو `GEMINI_API_KEY`) | `rc = EXIT_CONFIG_FAILED (3)` + الرسالة الصريحة التي تسمّي المتغيّر الناقص، بلا محاولة مستهلكة، وبلا ملف مكتوب، وبلا أي نداء شبكة |
| غياب المفتاح + `--dry-run` | `rc=0` بلا كتابة (لا ينكسر الاختبار الذاتي/CI) |

#### 5.4) ما لم يُختبر

- **لم يُختبر اتصال حقيقي بـGemini ولا بـGroq، ولا إرسال Telegram، ولا نشر GitHub Pages.** كل نتائج الأقسام 5.1–5.6 محلية وبلا شبكة (استجابات وهمية/مفتاح وهمي/`dry-run`)، ولا تُعدّ دليلاً على نجاح النشر الفعلي.
- `503` حقيقي من مزوّد Gemini لم يُختبر، ولا ردّ حقيقي من Groq (بما فيه `429` وتجاوز الحصة اليومية)، ولا خطأ شبكة حقيقي (`URLError`/`Timeout`) **من مزوّد**، ولا `Retry-After` بصيغة تاريخ HTTP (يُتجاهل ويعود للتراجع التصاعدي).
- **تحقّق المصادر الرسمية تمّ فعلياً عبر الشبكة** (hrsd/gosi/qiwa ترجع 200)، لكن **تقطّع DNS/503 حقيقي من مزوّد المصادر لم يُرصد**؛ التعامل معه مُختبَر باستجابات وهمية فقط (القسم 5.6). كذلك لم يُتحقّق أن السلوك يبقى صحيحاً لو حجب أحد المواقع الرسمية كل الطلبات بـ`403` (يُتوقّع عندها `draft_unverified` بلا نشر).
- لم يُتحقّق أن نموذج Groq الافتراضي `openai/gpt-oss-20b` متاح فعلاً لحساب المالك أو أنه ينتج JSON كاملاً دائماً؛ هذا يظهر عند أول تشغيل حقيقي (يُتوقّع عندها `invalid_content_json` أو `truncated_output` بوضوح إن اختلف السلوك).
- قيم `vars.AI_PROVIDER` و`vars.GROQ_MODEL` على GitHub وسلوك السير مع رمز خروج 2/3 لم تُشغَّل فعلياً على runner (اكتفاءً بـ`actionlint`).
- سير `ai_marketing.yml` شُغِّل فعلاً على runner مرّة واحدة (`workflow_dispatch`، وضع `draft`، بلا مفتاح فعلي) ونجح؛ لكن **سلوك السير عند رمز خروج 2 أو 3** (تخطّي خطوات النشر/الالتزام مع استمرار خطوات `if: always()`) مُستنتج من دلالات GitHub ولم يُنفَّذ فعلياً.
- `actionlint` (1.7.12) صار متاحاً محلياً ويمرّ على كلا ملفَي السير، لكنه لا يفحص سلوك المزوّد ولا الأسرار ولا الـrunner.
