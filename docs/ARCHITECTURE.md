الموقع ثابت ولا يملك backend خاصاً لتلقي مدخلات الحاسبات. مع ذلك، المتصفح يتصل بخدمات خارجية مثل Google Analytics 4 والخطوط والإعلانات؛ كما يتصل خط التسويق بمزوّد المحتوى والمصادر الرسمية اختيارياً عند التوليد.

## 2) تحميل الصفحة الرئيسية والخصوصية
1. يبدأ `index.html` بتهيئة اللغة والمظهر من معاملات URL والتفضيلات المحفوظة قبل CSS لتقليل الوميض.
2. يضبط كود GA4 قيمة `page_location` على أصل الصفحة ومسارها فقط، من دون query أو fragment.
3. يحمّل المتصفح CSS ومحتوى الأدوات؛ وتوجد تهيئة JavaScript الرئيسية في نهاية المستند.
4. عند فتح رابط مشاركة حساب، تُستعاد المدخلات، وتُحفظ فوراً في التخزين المحلي، ثم تزال معاملات المشاركة من العنوان. لا ينبغي مشاركة الرابط إلا مع من يسمح لهم الاطلاع على القيم الموجودة فيه.
5. يضيف Social Bar سكربت الإعلان ديناميكياً بعد حدث `load`. يوجد Native Banner منفصل؛ لا تكرّر السكربتات أو حاوية الإعلان.
6. يحتوي `privacy.html` على سياسة ثنائية اللغة ومبدّل للمظهر. يجب أن تتوافق الصياغة مع استخدام GA4 والإعلانات، لا أن توحي بأن كل معلومات الزيارة تبقى داخل المتصفح.

## 3) الأدوات الأساسية في `index.html`

| الدالة/المكوّن | الدور |
|---|---|
| `store` | غلاف آمن لعمليات `localStorage` |
| `applyBootPreferences()`, `applyI18n()`, `toggleLanguage()`, `applyTheme()` | اللغة والمظهر والتهيئة |
| `gosiScheme()`, `calculateSalary()` | اختيار خطة التأمينات وحساب الراتب والاستقطاعات |
| `calculateEOS()` | حساب المكافأة وبدل رصيد الإجازة وفق `docs/DOMAIN_RULES.md` |
| `parseLocalizedNumber()`, `normalizeDigits()`, `round2()`, `formatSAR()` | قراءة الأرقام المحلية والحساب النقدي والتنسيق |
| `eosSharePayload()`, `salSharePayload()`, `applyShareParams()` | إنشاء واستعادة روابط المشاركة |
| `persistInputsNow()`, `restoreInputs()` | الحفظ والاستعادة المحليان |
| `initTabs()`, `switchTool()` | التنقل بين الأدوات، بما في ذلك الروابط ذات `hashchange` |
| `generateLetter()`, `formatLetterDate()` | إنشاء الخطاب مع تنسيق التاريخ بحسب اللغة |
| `cvInit()`, `cvRender()`, `buildCV()`, `cvSharePayload()`, `cvYearsSpan()` | نموذج السيرة والمعاينة وفحص ATS وملخص الخبرة والمشاركة |
| `loadGuides()`, `renderGuides()`, `safeGuideUrl()` | عرض الأدلة من `articles.json` وقصر الروابط على المسارات المسموحة |
| `clear-local-data` | يمسح `seh_inputs_v2` بعد تأكيد المستخدم؛ ويحافظ على اللغة والمظهر |

### التخزين المحلي
- `seh_lang`: لغة الواجهة `ar/en`.
- `seh_theme`: المظهر `light/dark`.
- `seh_inputs_v2`: قيم النماذج المحفوظة محلياً.

هذا وصف لتخزين وظائف التطبيق. لا يعني أن طلبات الخدمات الخارجية لا تحتوي أي معلومات تقنية عن الزيارة. عناوين روابط المشاركة يمكن أن تحتوي الراتب والمدة والخيارات اللازمة لاستعادة الحساب؛ ويجري تنظيف معاملات الرابط بعد استعادة القيم.

## 4) الحسابات والقواعد القانونية
المعادلات والنسب التفصيلية وحالات الاستثناء موجودة في `docs/DOMAIN_RULES.md` وفي `index.html`. لا تُنسخ أرقام قانونية إلى هذه الوثيقة كمرجع مستقل، ولا تغيّر الحسابات أو الصياغات القانونية في إصلاح تقني من دون مراجعة موثوقة وموافقة بشرية.

- `calculateEOS()` يفصل المكافأة عن بدل الإجازة؛ يطلب الأجر الأساسي الحقيقي عند اختيار أساس الإجازة «الأساسي» بدلاً من تخمين قيمة مئوية.
- `gosiScheme()` يعالج خطة الاشتراك بحسب فئة المشترك وتاريخ الحساب؛ لا تفترض أن تغيير صاحب العمل يغير فئة التسجيل.
- `cvSharePayload()` يشارك نتيجة ATS والتغذية الراجعة ذات الصلة، لا نص السيرة أو الاسم أو الجوال أو البريد.
- المقالات القانونية عامة للتوعية وليست تحققاً آلياً من استحقاق حالة فردية.

## 5) مكتبة الأدلة وسلامة المقالات
- تعرض `articles/index.html` البيانات من `/articles.json` وتفلتر المنشور حسب اللغة المختارة. تبني العناصر النصية بواسطة `textContent` وتتحقق من روابط الصفحات قبل عرضها.
- قسم الأدلة في `index.html` يستخدم `safeGuideUrl()` لقبول روابط وفق شروطه؛ ويعرض حالة تحميل وفشل واضحة.
- المقالات الثابتة تتضمن canonical وhreflang وبيانات منظمة ومصادر رسمية. وجود الرابط لا يثبت أن المصدر ما زال صالحاً أو أن النص القانوني خضع لمراجعة حديثة.
- `tests/repository_consistency_test.py` يتحقق من أن سجلات `articles.json` تشير إلى ملفات موجودة، وأن أزواج اللغات وروابط sitemap لا تتناقض. لا يقيّم صحة مضمون القانون.

## 6) خط التسويق الآلي
- المزوّد الافتراضي الحالي: **Groq** مع النموذج `openai/gpt-oss-20b`.
- **Gemini** خيار صريح عبر `AI_PROVIDER=gemini`؛ النموذج الافتراضي المعرّف في السكربت/سير العمل هو `gemini-3.8-flash`.
- لا يوجد انتقال احتياطي تلقائي من مزوّد إلى آخر. فشل المزوّد المحدد يُسجل بوضوح.
- مفاتيح الوصول تُقرأ من متغيرات البيئة/أسرار Actions ولا ينبغي طباعتها. مفتاح التشغيل هو `GROQ_API_KEY` أو `GEMINI_API_KEY` بحسب المزوّد، وإعدادات Telegram اختيارية.

مراحل `auto_marketing.py`:
1. اختيار موضوع ولغة/لغتين استناداً إلى `TOPICS` وسجل المنشورات في `articles.json`.
2. الاتصال بالمزوّد المحدد وتفسير JSON الناتج.
3. التحقق من اللغة والحقول والطول والتكرار، والتدقيق الحتمي لأمثلة EOSB الرقمية عبر `eosb_reference_amount()` و`validate_eosb_calculation_example()`، ومقارنة مثال العربية بالإنجليزية عبر `validate_eosb_translation_pair()`.
4. قبول مصادر HTTPS من النطاقات المصرح بها فقط، مع حجب نطاقات وزارة العمل القديمة المنتهية من السياسة الحالية، ثم فحص الشبكة الفعلي عند السماح به. أي تعذّر تحقق يمنع النشر.
5. الوضع الافتراضي `draft`: المسودات خارج الملفات العامة، ولا تُحدّث `articles.json` أو `sitemap.xml`.
6. وضع `auto`: لا ينشر إلا زوج لغتين صالحاً وبعد فحص المصادر وإنشاء صفحات مرحلية والتحقق من HTML والفهارس وsitemap.
7. قد ينتج منشوراً اجتماعياً ويمرر اختيارياً رسالة إلى Telegram بعد النشر؛ الاختبارات الوهمية لا تثبت نجاح التكامل الحقيقي.

رموز الخروج: `0` إتمام آمن/مسودة، `1` خطأ داخلي، `2` لا توجد نسخة محتوى صالحة، `3` مفتاح المزوّد غير مضبوط، `4` محاولة نشر غير آمنة مع تخطي فحص المصادر.

## 7) النشر وسير CI
- `.github/workflows/ai_marketing.yml`: تشغيل مجدول يومياً عند 09:00 بتوقيت `Asia/Riyadh` أو يدوياً؛ `PUBLISH_MODE` افتراضياً `draft`. المسودات تُرفع كـ artifact للمراجعة ولا تُنشر بوصفها صفحات عامة.
- `.github/workflows/ci.yml`: CI لطلبات الدمج يملك صلاحيات قراءة المحتويات، ولا يستدعي توليد محتوى حقيقياً ولا ينشر. يشمل `py_compile`، و`--selftest`، و`--verify`، و`node --check`، و`git diff --check`، و`tests/repository_consistency_test.py`، و`tests/smoke_test.py`، ومقارنة PDF عند تغيّر CSS الطباعة.

## 8) حدود ما تثبته الاختبارات
- الاختبارات الوهمية للـAI لا تثبت أن الحساب الحقيقي يملك حصة API كافية أو أن المزوّد يعيد محتوى صالحاً في كل تشغيل.
- حجب الشبكة أثناء اختبار المتصفح يعني أن CI لا يثبت عرض الإعلانات الحقيقية أو قياس GA4.
- فحص الروابط داخل الفهرس وsitemap لا يثبت استجابة الجهات الخارجية الآن أو التوافق القانوني للمقال.
- تغيّر قاعدة `@media print` يستلزم مقارنة PDF؛ لا تدمج كتل CSS للطباعة لمجرد التنسيق دون تمرير هذه المقارنة.
- ينبغي تسجيل نتيجة CI لكل التزام؛ لا تُعامل عدداً تاريخياً من الاختبارات كأنه نتيجة الاختبار الحالي.
